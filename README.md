# Snowboard Paradise

A free 3D snowboard game that runs in the browser on phones and computers.
Race bots, land flips, spins and grabs, and unlock 18 mountains, 12 riders and new gear.

Play: https://snowboard-paradise.github.io/

The whole game is in `index.html`. The other files are icons, the share image, the web app manifest,
the offline service worker (`sw.js`) and the sitemap for Google.
